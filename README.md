## 🖼️ Tampilan Aplikasi

### 1. Halaman Utama (Katalog & Tabel Stok)
> Menampilkan seluruh daftar mobil Porsche lengkap dengan kategori, harga, stok, serta tombol aksi (Edit & Hapus).

### 2. Halaman Tambah Data
> Formulir interaktif untuk memasukkan unit mobil Porsche baru ke dalam database.

### 3. Halaman Edit Data
> Formulir untuk memperbarui informasi unit mobil yang sudah ada.

---

## 🚀 Fitur Utama
* **Create:** Menambahkan data unit mobil Porsche baru (Nama Model, Kategori, Harga, Stok, Gambar, dan Deskripsi).
* **Read:** Menampilkan daftar seluruh unit mobil dalam bentuk tabel responsif.
* **Update:** Mengubah atau memperbarui data unit mobil yang sudah ada.
* **Delete:** Menghapus data unit mobil dari database.
* **UI/UX:** Menggunakan kerangka kerja **Bootstrap 5** dengan tema gelap yang elegan.
